# ⚜️ Tabela do Brasileirão — Web Scraping Profissional com Selenium

Este projeto realiza **Web Scraping** direto do site oficial da **CBF** para extrair, limpar e estruturar a tabela atualizada do **Campeonato Brasileiro Série A – 2025**.  
Os dados são organizados em um **DataFrame pandas** e armazenados em um **banco SQLite**, permitindo análises e consultas futuras.

---

## ✨ Visão Geral

A aplicação utiliza:

- **Selenium WebDriver** para automação e captura dinâmica dos dados.
- **Pandas** para tratamento e estruturação da tabela.
- **SQLite** para persistência simples, leve e eficiente.
- **XPath** e busca estruturada para extrair exatamente as colunas exibidas pela CBF.

O resultado é um pipeline compacto, rápido e confiável para armazenamento dos dados da rodada.

---

## 🧠 Tecnologias Utilizadas

| Ferramenta | Finalidade |
|-----------|------------|
| 🟦 Python | Linguagem principal |
| 🔍 Selenium | Automação e Web Scraping |
| 🧮 Pandas | Limpeza e organização dos dados |
| 🗂️ SQLite | Armazenamento local |
| 🌐 XPath | Localização precisa dos elementos |

---

## 📌 Funcionalidades

✔️ Captura automática da tabela completa do Brasileirão  
✔️ Remove pop-ups e bloqueios do site  
✔️ Extrai colunas, limpa caracteres e reorganiza dados  
✔️ Corrige inconsistências de classificação  
✔️ Exporta tudo automaticamente para o SQLite  
✔️ Código limpo, direto e escalável
